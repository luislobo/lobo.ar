# lobo.ar

Interactive 3D LOBO.AR wolf landing page.

## Model

Place the generated GLB at:

`assets/lobo-wolf.glb`

The page uses Google's `<model-viewer>` web component for orbit controls, touch gestures, lighting and auto-rotation.

## Run locally

Serve the directory over HTTP (opening index.html directly may block model loading). For example:

`python3 -m http.server 8080`

Then open `http://localhost:8080`.
